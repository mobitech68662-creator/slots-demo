# Slots Demo - Simple Betting Site

Simple slots betting demo with virtual credits only.

## Features
- User registration/login
- 3 Slot Games (Super Ace, Fortune Gems, Lucky 777)
- Virtual wallet system
- Bet history

## Quick Start

```bash
# Install dependencies
npm install

# Start database
npm run docker:up

# Run dev servers
npm run dev
```

**Frontend:** http://localhost:3000
**Backend:** http://localhost:3001
